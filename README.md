# King Me — Checkers

A two-player American checkers game in the browser.

## Rules

- Crimson moves first
- Move diagonally forward on dark squares
- Jumps are mandatory; multi-jumps continue with the same piece
- Reach the far row to become a king (moves both directions)
- Win by capturing all opponent pieces or leaving them with no moves

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
